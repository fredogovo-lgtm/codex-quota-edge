额度显示 v2.2.2：Codex 额度小面板

作用：显示 5 小时剩余额度、距重置倒计时和本周剩余额度，随 Codex 启动和退出。

1. 将完整 ZIP 全部解压，双击 Enable-Follow.vbs 启用或升级。
2. 单击切换样式，悬停看详细数字；拖到屏幕四边定位。
3. 右键可锁定位置、选择“置顶显示 / 取消置顶”；下次启动记住选择。
4. 不用时双击 Disable-Follow.vbs 停用。

source 文件夹是对应的完整源码，普通使用无需打开。
适用 Windows 10/11 x64，已安装并登录标准商店版 Codex。
源码和下载：https://github.com/fredogovo-lgtm/codex-quota-edge
额度来自本机 Codex CLI 登录账号；本工具非 OpenAI 官方产品，不增加额度。
开启置顶后自动维护普通窗口层级，不抢键盘焦点；系统受保护界面除外。
